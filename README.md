# Wallpaper Gallery Web App

A responsive wallpaper gallery web application built using modern frontend technologies. The app displays a collection of high-quality wallpapers in a clean grid layout with smooth responsiveness across all devices.

## 🚀 Live Demo
👉 Try it here: https://sunnyjaybhay.github.io/Wallpaper/

## ✨ Features
- Responsive gallery layout for mobile, tablet, and desktop
- Clean and modern user interface
- Fast loading and easy to navigate
- Simple to customize and extend

## 🛠 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript**
